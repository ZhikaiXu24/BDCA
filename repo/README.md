# Kimodo

Kimodo generates 3D motion from text and constraints. This source tree includes
the G1 generation and export code used by the integrated project.

See the [project README](../README.md) for installation, model weights and the
GEM-X to G1 workflow. See [upstream Kimodo documentation](https://research.nvidia.com/labs/sil/projects/kimodo/docs/index.html)
for the original package. [License](LICENSE) and [attributions](ATTRIBUTIONS.MD).
